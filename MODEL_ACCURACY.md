## Input Features

The model classifies EEG signals using 5 statistical features extracted from each signal window:

| # | Feature | Description |
|---|---------|-------------|
| 1 | **Mean** | Average signal amplitude |
| 2 | **Std Dev** | Standard deviation of amplitude |
| 3 | **Variance** | Signal variance |
| 4 | **Min Amplitude** | Minimum signal value |
| 5 | **Max Amplitude** | Maximum signal value |

## Methodology Notes

### Test Data Generation
Since the original `train_data.csv` / `test_data.csv` files are not committed to the repository (only the serialized `.pkl` artifacts are), the evaluation script reconstructs a test set by:

1. Sampling 5,000 feature vectors from a Gaussian distribution matching the `StandardScaler`'s learned mean and scale (i.e., the same distribution the model was trained on).
2. Running the model on each sample and collecting high-confidence predictions (top 500 per class).
3. Using those predictions as ground truth for the final evaluation pass.

This is a **self-consistency test** — it measures how well the model has learned to separate its own training distribution. It is **not** equivalent to held-out test accuracy on unseen real-world EEG recordings.

### To Run a True Evaluation
If you have access to the original labeled EEG dataset, place it at the project root as `test_data.csv` (features in columns 0–4, label in the last column) and run:

```bash
cd backend
python serialize.py   # re-trains and writes metrics.json from real test data
```

Or run the standalone evaluation script directly:

```bash
cd backend
python evaluate_model.py
```

## Re-Training

To retrain the model from scratch with new data:

1. Place `train_data.csv` and `test_data.csv` in the project root (label in the last column).
2. Run:
   ```bash
   cd backend
   python serialize.py
   ```
3. This overwrites `models/random_forest_model.pkl`, `models/scaler.pkl`, and `models/metrics.json`.
